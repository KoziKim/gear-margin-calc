# 🎛️ GearCalc (해외 악기·장비 순마진 계산기)

해외 직구(Reverb 등) 가격과 국내 중고(뮬, 번개장터 등) 판매가를 입력하면, 관세 구간(한미 FTA 목록통관 면세 / 부가세 10% / 일반 관부가세), 한국 배대지 비용, 실시간 환율을 반영하여 **예상 순마진**과 **손익분기점**을 실시간으로 계산해 주는 모던 반응형 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **실시간 정밀 조달원가 산출**
   - **$200 이하**: 관부가세 0% (미국 목록통관 전액 면세)
   - **$200 초과 ~ $1,000 이하**: 한미 FTA 원산지 적용 부가세 10%만 부과
   - **$1,000 초과**: 일반 관부가세 (약 18.8%) 부과
   - 한국행 배대지 비용(기본 $25) 및 환율(기본 1,360원) 커스텀 조정 가능

2. **국내 판매 수익성 평가**
   - 뮬 직거래(수수료 0%) 및 번개페이/안전결제 수수료(3.5~5%) 옵션 지원
   - 순마진 3만 원 이상 시 `🚀 매수 추천` 뱃지 및 마진율(%) 즉각 표시
   - 본전 판매를 위한 **손익분기점(Break-even) 최소 판매가** 자동 계산

3. **빠른 템플릿 프리셋**
   - 킹오브톤 (King of Tone), Line 6 HX One, 시크릿 프리앰프, 킬리 헤일로 등 대표 타깃 장비 1클릭 프리셋 지원

4. **공유 링크 지원**
   - 현재 입력한 가격과 조건이 그대로 포함된 URL을 1클릭 복사하여 저장 및 공유 가능

## 🚀 로컬 실행 방법

별도의 서버 설치 없이 브라우저에서 `index.html`을 바로 열거나, 간단한 웹 서버로 구동할 수 있습니다:

```bash
# Python 내장 서버로 실행 (추천)
python3 -m http.server 3000

# 브라우저 접속: http://localhost:3000
```

## 🌐 1분 무료 배포 (GitHub Pages)

이 저장소는 정적 웹앱(Static Web App)으로 제작되어 **GitHub Pages**를 통해 완전 무료로 1분 만에 배포할 수 있습니다:

1. GitHub 저장소 상단 **[Settings]** 탭 클릭
2. 좌측 메뉴에서 **[Pages]** 클릭
3. **Build and deployment** > **Branch**를 `main` / `/ (root)` 로 선택 후 **[Save]** 클릭
4. 1~2분 뒤 `https://KoziKim.github.io/gear-margin-calc` 주소로 즉시 전 세계 어디서나 모바일/PC로 접속 가능!
